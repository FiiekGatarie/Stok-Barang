# 🛒 Aplikasi Manajemen Stok Barang - Grosiran Snack

Aplikasi web sederhana berbasis **PHP** dan **MySQL** untuk mengelola stok barang di toko grosiran snack. Sistem ini memudahkan pengguna dalam memantau, menambah, mengedit, dan menghapus data barang. Dilengkapi juga dengan notifikasi ketika stok hampir habis dan fitur dark mode.

## ✨ Fitur Utama

- 📦 Manajemen stok barang
- 📥 Input barang masuk
- 📤 Input barang keluar
- ⚠️ Notifikasi stok rendah (kurang dari 5)
- 🌙 Mode gelap (dark mode toggle)
- 📄 Export data ke file
- 🔐 (Opsional) Autentikasi pengguna dengan `cek.php`

## 🛠️ Teknologi yang Digunakan

- PHP
- MySQL
- Bootstrap 5
- FontAwesome Icons
- Simple DataTables
- Chart.js *(opsional, untuk grafik)*
